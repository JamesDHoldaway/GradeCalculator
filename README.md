# GradeCalculator

Creating a basic calculator for practice with R and webR (web hosting)

This is an educational project using R and webR. My inspiration came from a task in my data science toolkit course at NCSU where we were tasked to make a calculator for an example student who had differently weighted factors with predetertimned scores contributing to his final grade in a course. 
I completed the task then went beyond the requirements of that assignment to make an interactive calculator with the option to input your own personal grades.

My goal for this project is to create a grade calculator that is hosted locally in the web using webR. This calculator will allow the user to choose their own factor with their own weights, and input their own score to get a personalized answer.
